# 포근 쉼터 (Pogeun Shelter)

전국 강아지 파양입소 · 무료분양 안내 사이트 (Next.js).

관리자·대량발행·IndexNow 구조는 달빛쉘터와 동일하며, 디자인/문구만 [K-Beauty Station](https://www.kbeautystation.co.kr/) 톤의 핑크 테마로 재작업했습니다.

## 로컬 실행

```bash
npm install
npm run dev
```

## 배포

`VERCEL_SETUP.txt` 참고. **다른 보호소의 Blob/JWT/IndexNow 키를 재사용하지 마세요.**
